ℹ️ About This Project

Understanding the Applied AI concepts behind the AI Prompt Generator

🎯 Project Overview

The AI Text-to-Image Prompt Generator is a mini web application that demonstrates key concepts from Applied Artificial Intelligence (AAI). It transforms simple, natural language descriptions into optimized, detailed prompts suitable for AI image generation tools like DALL·E, Stable Diffusion, and Midjourney.

🧠 Applied AI Concepts Used

1. Prompt Engineering

Prompt engineering is the art of crafting effective inputs for AI models. This application uses template-based prompt engineering to systematically enhance user descriptions with style-specific modifiers, lighting descriptors, mood keywords, and quality boosters that are known to produce better results in diffusion-based image models.

2. Natural Language Processing (NLP)

The system parses and processes natural language input from users, understanding the semantic intent and restructuring it into a format optimized for AI consumption. This includes text normalization, keyword extraction, and contextual augmentation.

3. Knowledge-Based / Rule-Based AI System

The prompt engine operates as a knowledge-based system containing curated domain knowledge about art styles, lighting techniques, composition rules, and quality descriptors. It uses rule-based logic to select and combine the most appropriate modifiers for each style category.

4. Human-AI Interaction (HAI)

The application demonstrates effective human-AI interaction design principles: intuitive input interfaces, visual style selection, real-time feedback, contextual tips, and a gallery view for prompt management. It bridges the gap between human creativity and AI capability.

5. Generative AI Workflows

Understanding how text-to-image diffusion models interpret prompts is central to this project. The system encodes knowledge about how models like Stable Diffusion weight different keywords, the importance of negative prompts, and how style-specific tokens influence the generated output.

⚙️ How It Works

1

User Input

User types a simple description like "a cat sitting on the moon"

2

Style Selection

User chooses an art style (e.g., Photorealistic, Anime, Oil Painting)

3

AI Prompt Engine

The engine applies style-specific modifiers, lighting, mood, quality boosters, and aspect ratio tags

4

Output

An optimized prompt + negative prompt ready to paste into any AI image generator

5

Storage

The prompt is saved to the SQLite database for future reference, search, and favorites
